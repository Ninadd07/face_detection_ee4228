# VGGFace Friend Recognition Guide (Shreyas)

This document summarizes what was implemented for Project 2, what model is being used, where outputs are stored, and how to run training and live webcam inference.

## What We Built

We implemented an end-to-end VGGFace-based friend recognition pipeline in `project_2/shreyas`.

Main components:

- `preprocess_dataset.py`
  - Validates dataset folder structure and image counts.
  - Writes dataset summary to `artifacts/dataset_summary.json`.
- `train_vggface.py`
  - Fine-tunes a VGGFace (VGG16 backbone) classifier for 7 classes.
  - Freezes most base layers and fine-tunes top layers (`conv5*` + custom dense head).
  - Saves model and metadata artifacts.
- `live_webcam_vggface.py`
  - Opens webcam.
  - Detects faces in live frames.
  - Classifies each detected face and overlays name + confidence.
  - Supports `Unknown` labeling with confidence threshold.
- `keras_vggface_compat.py`
  - Runtime compatibility shim so `keras-vggface` works with the current environment.

## Dataset Used

- Folder: `training_images_augmented`
- Structure: `training_images_augmented/<PersonName>/*.jpg`
- Current dataset summary: 7 classes, 4200 total images.

## Model and Artifacts

Artifacts are stored in `project_2/shreyas/artifacts`:

- `vggface_friends.keras` : trained model weights + graph (Keras format)
- `class_indices.json` : class index mapping used at inference
- `dataset_summary.json` : dataset stats from preprocessing
- `training_history.csv` : training metrics per epoch (if generated by a completed run)

## Model Behavior Notes

- Input shape: `(224, 224, 3)`
- Output shape: `(None, 7)` (7 friend classes)
- Confidence threshold controls `Unknown` behavior:
  - Higher threshold: fewer false positives, more `Unknown`
  - Lower threshold: fewer `Unknown`, more risk of wrong identity
